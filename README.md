📦 Medicament Scraper (Morocco)

A simple Node.js web scraper that extracts medication data from medicament.ma and exports it into a structured CSV file.

This project collects publicly available medication listings and transforms them into a clean dataset for analysis and integration.

🚀 Features
Scrapes medication listings from medicament.ma
Extracts raw medication names (MVP version)
Exports data into CSV format
Lightweight and easy to extend
Built with Node.js + Cheerio
🧰 Tech Stack
Node.js
Axios
Cheerio
csv-writer
📁 Output

Generates a medicaments.csv file containing extracted medication data.

⚠️ Disclaimer

This project is for educational and research purposes only.
Data is collected from publicly accessible web pages.
